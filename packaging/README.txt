交谈话题 Conversation Starter — 离线版
========================================

双击「交谈话题.html」即可使用。
不用安装，不用联网，不会上传任何数据。

第一次用请先看「使用说明.html」（也是双击打开）。

Windows 用户：如果文件名显示为乱码，请改用 7-Zip 或
Bandizip 重新解压一次，文件本身没有损坏。
